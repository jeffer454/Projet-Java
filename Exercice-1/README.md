# Exercice-1 — Informations personnelles d'un étudiant

## Objectif
Manipuler les variables, les types de données primitifs, l'entrée utilisateur (`Scanner`) et l'affichage formaté en console.

## Ce que fait le programme
Le programme demande à l'utilisateur :
- Le nom
- Le prénom
- L'âge
- La moyenne

Puis il affiche :
- Toutes les informations saisies
- Si l'étudiant est admis (moyenne ≥ 12) ou échoué
- La mention associée (Insuffisant, Passable, Assez-Bien, Bien, Très-Bien, Honorable)
