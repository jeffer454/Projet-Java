# Exercice-2 — Calculatrice avec menu

## Objectif
Mettre en place un menu interactif en console et implémenter plusieurs opérations mathématiques : addition, soustraction, multiplication, division et factoriel.

## Ce que fait le programme
Affiche un menu répétitif avec les options suivantes :
1. Addition
2. Soustraction
3. Multiplication
4. Division
5. Factoriel
q. Quitter

Selon le choix de l'utilisateur, le programme exécute l'opération correspondante sur les valeurs saisies.
